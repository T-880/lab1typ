# Laboration 1 - Grunderna i TypeScript

Denna applikation är utvecklad för att hantera kurser med kurskod, kursnamn, progression och länk till kursplan. Fokus har legat på att skapa en dynamisk webbapplikation där användaren kan lägga till nya kurser, visa alla kurser och radera kurser. Applikationen använder TypeScript med hård typning för robust kod, Vite som byggverktyg, samt localStorage för att spara kursdata mellan sessioner. Kursinformationen uppdateras dynamiskt på sidan med DOM-manipulation och enkel validering säkerställer unik kurskod och korrekt progression (A, B eller C). All styling och layout är enkel, prydlig och responsiv för både desktop och mobil.
